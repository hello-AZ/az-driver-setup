AZ 驱动懒人安装 —— 便携版（免安装）
========================================

解压到任意可写目录即可使用，例如：
    D:\Tools\AZ驱动懒人安装\
    U 盘根目录\AZ驱动懒人安装\

不需要安装，也不写注册表。


使用方法
--------
1. 右键 DriverSetup.exe → 「以管理员身份运行」
   （必须提权：读传感器、装驱动都需要管理员）

2. 首次运行会在本目录自动创建：
       Downloads\    从联想官网下载的驱动安装包（原样保留，不改名）
       Backup\       驱动备份（每次约 4~5 GB，很占空间）
       debug.log     运行日志，出问题时把这个发出来

3. 装驱动前建议先点「备份驱动」，装错了可以回滚。


卸载
----
直接删掉整个文件夹。
（没有注册表项、没有系统目录残留，前提是没通过安装版装过）


系统要求
--------
Windows 10 1809（17763）及以上 / Windows 11，x64。
Windows 8 / 8.1 不支持（.NET 8 最低要求 Win10 1607）。
.NET 运行时已内置，无需另外安装。


已知限制
--------
- 海外版 / 水货机器：驱动清单可能返回 0 条
  联想驱动库按销售区域收录，国内站没有海外机型的驱动记录
- 刚上市 1~2 个月的机型：官方驱动库可能还没录入
- ThinkPad 等非 Legion 机型：部分部件类别未覆盖，会显示「待确认」
- 仅支持联想。其他品牌会提示「暂不支持」并给出通用驱动方案


安全说明
--------
- BIOS / EC / ME 固件永不自动执行，需要用户自己去官网下载并手动刷
- 驱动清理只允许删除本工具安装并登记过的驱动
- 只访问 newsupport.lenovo.com.cn，不上报任何数据，无遥测
- 驱动安装包全部来自联想官网，本程序不打包、不分发驱动文件
