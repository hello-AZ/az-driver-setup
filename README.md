# AZ 驱动懒人安装

> 读本机序列号 → 查联想官网驱动清单 → 与本机已装版本逐条比对 → 下载并静默安装。
> 另带配置核对、固件提示、驱动备份回滚、硬件测试、压力测试、系统排查。

**不是联想官方工具**，驱动全部来自联想官网公开接口，下载行为等同手动去官网下载。

---

## 适用范围

| 项目 | 支持情况 |
|---|---|
| **厂商** | 联想（可自动查驱动）；华硕/天选、惠普、荣耀、华为、机械革命（仅引导到官网） |
| **系统** | **Windows 10 1809（17763）及以上 / Windows 11**，x64 |
| **架构** | x64 |
| **权限** | 必须管理员运行（读传感器、装驱动都需要） |

### 已知限制（请务必先看）

| 情况 | 表现 | 原因 |
|---|---|---|
| **海外版 / 水货机器** | 驱动清单返回 0 条 | 联想的驱动库按销售区域收录，国内站没有海外机型的驱动 |
| **刚发布 1~2 个月的新机型** | 可能没有驱动 | 官方驱动库更新晚于开卖 |
| **停产 5 年以上的老机型** | 可能查不到 | 联想已停止支持 |
| **ThinkPad / IdeaPad 等新部件类别** | 部分条目落在「待确认」 | 只实测过 Legion 的 17 种部件类别 |
| **台式机 / 一体机** | 可能匹配不准 | 主要针对笔记本设计 |
| **其他品牌**（Dell / HP / ASUS） | 显示「暂不支持该厂商」并给出通用驱动方案 | 尚未实现 |
| **Windows 8 / 8.1** | **装不上** | .NET 8 最低要求 Windows 10 1607，Win8.1 连运行时都不支持 |

遇到前四种情况，程序会明确提示，并给出「通用驱动」的应急路径（Intel DSA / NVIDIA 官网 / OEM 官网）。

## 厂商支持

| 厂商 | 读机型 | 驱动清单 | 说明 |
|---|---|---|---|
| **联想**（含拯救者 / 小新 / ThinkPad、ThinkBook） | ✅ 官网档案 | ✅ **官方接口** | 唯一能自动查询驱动的 |
| **华硕 / 天选** | ✅ 本地 WMI | ❌ | 官网无公开接口，页面引导 |
| **惠普** | ✅ 本地 WMI | ❌ | 官网 403 挡爬虫，连页面都抓不到 |
| **荣耀** | ✅ 本地 WMI | ❌ | 页面引导 |
| **华为** | ✅ 本地 WMI | ❌ | 页面引导 |
| **机械革命** | ✅ 本地 WMI | ❌ | 页面引导 |
| **其他品牌** | ✅ 本地 WMI | ❌ | 显示「暂不支持」+ 通用驱动方案 |

**非联想机型的实际体验**：

- **配置核对 / 硬件测试 / 压力测试 / 系统排查 全部可用**（走 WMI、EDID、Raw Input，与品牌无关）
- 驱动页会显示：

```
华硕官网暂未开放驱动查询接口
本机机型：ASUSTeK COMPUTER INC. ...

程序能读到本机硬件信息（见「配置核对」页），但拿不到华硕的驱动清单。
请点击下方按钮前往官网，按机型或序列号自行下载对应的驱动。

[打开华硕驱动下载页]
https://www.asus.com.cn/support/
```

## 功能

| 分区 | 内容 |
|---|---|
| **配置核对** | CPU / 显卡 / 内存 / 硬盘 / 屏幕（EDID 含色域）/ 电池（健康度、循环次数）/ 网卡，全部只读采集 |
| **驱动安装** | 官网清单比对（可更新 / 已最新 / 比官网新 / 未安装 / 非本机配置），逐条下载静默安装，装完校验 |
| **固件提示** | BIOS / EC / ME 固件**只展示与说明，永不自动执行**，附官网链接 |
| **备份回滚** | `pnputil /export-driver` 全量备份，可逐条回滚，失败明细写 `restore-errors.txt` |
| **硬件测试** | 键盘（三套布局：104 全尺寸 / 102 联想式 / 14 寸无小键盘）、鼠标（五键 + 回报率 + 1:1 轨迹）、屏幕坏点、刷新率 |
| **压力测试** | CPU 烤机（每核频率 + 温度曲线）、GPU 烤机（D3D11 全屏负载 + FPS / 频率 / 功耗） |
| **系统排查** | 蓝屏记录分析（WMI Event 1001）、驱动清理（只允许删本工具安装并登记过的驱动） |

## 两种形态

| 形态 | 适用场景 | 数据位置 |
|---|---|---|
| **安装版** `AZ-DriverSetup-Setup-<版本>.exe` | 长期使用 | `C:\Program Files\AZ驱动懒人安装\`，有开始菜单与卸载入口 |
| **便携版** `AZ-DriverSetup-Portable-<版本>.zip` | 临时用 / 放 U 盘 | 解压目录（`Backup\`、`Downloads\`、日志都在那里），删文件夹即卸载 |

便携版解压后先读 `使用说明.txt`，使用方式与安装版相同。

## 使用

1. 右键 `DriverSetup.exe` → **以管理员身份运行**（或安装版直接双击，会弹 UAC）
2. 程序自动读取序列号并查询官网清单
3. 勾选要装的驱动 → 点「安装选中」
4. **装驱动前建议先点「备份驱动」**（体积可能数 GB，占空间）
5. 装完按提示重启

首次运行后，程序目录下会自动出现：

- `Downloads\` —— 从官网下载的驱动包（原样保留，不改名不删字节）
- `Backup\` —— 驱动备份（每次约 4~5 GB）
- `debug.log` —— 运行日志，出问题时把这个发出来
- `install-history.json` —— 安装台账，驱动清理页据此判断哪些是本工具装的

## 卸载

| 形态 | 方式 |
|---|---|
| **安装版** | 程序内**右侧栏底部**「关于 / 卸载」→「卸载本程序」<br>或：设置 → 应用 → AZ 驱动懒人安装 → 卸载 |
| **便携版** | 直接删除整个文件夹，无注册表残留 |

⚠️ 卸载会**同时删除** `Downloads`（驱动包）和 `Backup`（驱动备份）。需要留的备份请先拷走。

## 安全说明

| 项目 | 做法 |
|---|---|
| **BIOS / EC / ME 固件** | **永不自动执行**。只显示版本对比和官网说明，需要用户自己去官网下载并手动刷 |
| **高危驱动** | 默认不勾选 |
| **外设驱动**（键盘/鼠标/G HUB 等） | 不在列表内，需用户自行安装 |
| **驱动清理** | 只允许删除本工具安装并登记在 `install-history.json` 里的驱动，其余条目勾选框禁用 |
| **装错驱动** | 可通过「备份回滚」恢复；回滚使用 `pnputil /add-driver ... /install`，幂等 |
| **远程请求** | 只访问 `newsupport.lenovo.com.cn`，不上报任何数据，无遥测 |

## 从源码构建

需要 .NET 8 SDK（或更高）。

```bat
:: 普通构建（需要目标机器已装 .NET 8 Desktop Runtime）
dotnet build Src\DriverSetup.csproj -c Release -o Src\bin\net8

:: 自包含发布（体积约 150 MB，目标机器不需要装 .NET）
dotnet publish Src\DriverSetup.csproj -c Release -r win-x64 --self-contained true -o Dist\App
```

### 打安装包

```bat
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" Installer\setup.iss
```

产物在 `Dist\Installer\`。
